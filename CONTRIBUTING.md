# Contributing to Symmetra

Thank you for your interest in contributing to Symmetra!

## About This Repository

This repository contains **compiled binaries and installation files only**. The Symmetra source code is proprietary and not publicly available.

## How You Can Contribute

### 📣 Report Issues

Found a bug? Have a feature request?

1. Check [existing issues](https://github.com/JvanDyk/Symmetra/issues) to avoid duplicates
2. Open a [new issue](https://github.com/JvanDyk/Symmetra/issues/new) with:
   - Clear title and description
   - Steps to reproduce (for bugs)
   - Your environment (OS, driver version, GPU model)
   - Error messages or logs

### 🔒 Report Security Issues

**Do not open public issues for security vulnerabilities.**  
Email [security@symmetra.dev](mailto:security@symmetra.dev) instead. See [SECURITY.md](SECURITY.md) for details.

### 💬 Join Discussions

- [Ask questions](https://github.com/JvanDyk/Symmetra/discussions/new?category=q-a)
- [Share ideas](https://github.com/JvanDyk/Symmetra/discussions/new?category=ideas)
- [Show your work](https://github.com/JvanDyk/Symmetra/discussions/new?category=show-and-tell)

### 📝 Improve Documentation

Help improve:
- [Getting Started Guide](https://symmetra.dev/docs/getting-started)
- [API Documentation](https://symmetra.dev/docs/api)
- Examples and tutorials
- Website content

Create issues or discussions for documentation improvements.

### 🤝 Community

- Be respectful and inclusive
- Follow the [Contributor Code of Conduct](#code-of-conduct)
- Help other users in discussions
- Share your experiences and use cases

## What We Can't Accept

- Source code contributions (source is proprietary)
- Engine patches (engine is not open-source)
- Pull requests modifying binary files
- Attempts to reverse-engineer the engine

## Code of Conduct

### Our Pledge

We are committed to providing a welcoming and inclusive environment for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, sexual identity and orientation, socioeconomic status, or technical ability.

### Expected Behavior

- Be respectful and professional
- Welcome diverse perspectives
- Give and accept constructive feedback gracefully
- Focus on what is best for the community
- Show empathy towards other community members

### Unacceptable Behavior

- Harassment, discrimination, or abuse
- Personal attacks or insulting comments
- Unwelcome sexual advances
- Publishing others' private information
- Any form of violence or threats

### Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported by contacting the project maintainers at [support@symmetra.dev](mailto:support@symmetra.dev). All complaints will be reviewed and investigated promptly and fairly.
