🚀 QUICK START - 3 WAYS TO USE:

[1] WEB PROJECT (Easiest)
   ─────────────────────
   Step 1: Copy FirstLight.ttf to your project folder
   Step 2: Add this to your CSS:
           @font-face {
               font-family: 'First Light';
               src: url('FirstLight.ttf') format('truetype');
           }
   Step 3: Use in HTML:
           <h1 style="font-family: 'First Light', Arial, sans-serif;">
               FIRST LIGHT
           </h1>

[2] SYSTEM-WIDE INSTALLATION (Windows)
   ────────────────────────────────────
   Step 1: Right-click FirstLight.ttf
   Step 2: Select "Install" or "Install for all users"
   Step 3: Font available in Word, Photoshop, etc.

[3] SYSTEM-WIDE INSTALLATION (Mac)
   ────────────────────────────────
   Step 1: Double-click FirstLight.ttf
   Step 2: Click "Install Font" button
   Step 3: Font available in all Mac applications

📋 MINIMUM CSS TO USE FONT:

.first-light {
    font-family: 'First Light', Arial, sans-serif;
    font-size: 120px;
    font-weight: normal;
    letter-spacing: 8px;
    color: white;
}

═══════════════════════════════════════════════════════════════════════════════
🎨 KEY SETTINGS TO REMEMBER:

FONT WEIGHT:     Use "normal" NOT "bold"
LETTER SPACING:  Use 8px or more (looks better)
TEXT TRANSFORM:  "uppercase" recommended
COLOR:           White or light colors work best
BACKGROUND:      Dark background looks professional
SIZE:            Works best at 48px+

🔧 ADDING MORE CHARACTERS (For Advanced Users):

1. Open generate_3d_font.py in a text editor
2. Find the create_letter_outline() function
3. Add new letter definitions:

   ord('A'): [(100, 0), (300, 600), (500, 0), ...],  # New letter
   ord('B'): [(100, 0), (500, 0), (500, 300), ...],  # Another letter

4. Save the file
5. Run: python generate_3d_font.py
6. New FirstLight.ttf with added characters will be generated

💡 CUSTOMIZATION EXAMPLES:

Add Shadow/Depth:
    text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);

Add Glow Effect:
    text-shadow: 0 0 10px rgba(255, 255, 255, 0.5);

Make Responsive:
    @media (max-width: 768px) {
        h1 { font-size: 60px; }
    }

Gradient Text:
    background: linear-gradient(135deg, #fff, #ccc);
    -webkit-background-clip: text;
    -webkit-text-fill-color: transparent;

❓ TROUBLESHOOTING:

Font not loading in browser?
→ Check file path is correct (relative or absolute)
→ Verify font file is in the right location
→ Check browser console for errors

Font looks wrong?
→ Make sure font-weight is "normal" not "bold"
→ Increase letter-spacing (8px+)
→ Use larger font-size (40px+)

Can't install system-wide (Windows)?
→ Run as Administrator
→ Disable antivirus temporarily
→ Try right-click > "Install for all users"
