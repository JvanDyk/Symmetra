🔧 How to Use

Copy the SVG code below and customize for your project:

<svg viewBox="0 0 120 160" xmlns="http://www.w3.org/2000/svg">
  <!-- Shadow layers for 3D effect -->
  <g id="shadow">
    <rect x="4" y="4" width="112" height="152" rx="8" fill="rgba(0,0,0,0.3)" opacity="0.8"/>
  </g>

  <!-- Main letter -->
  <g id="letter">
    <path d="M 20 50 L 100 50 L 100 65 L 50 65 L 50 110 L 100 110 L 100 125 L 20 125 Z"
          fill="#ffffff" stroke="#f0f0f0" stroke-width="1.5"/>
  </g>
</svg>

🎯 Design Details

The font design is inspired by cinematic title sequences with authentic 3D depth. Each character uses layered shadows at different angles to create the illusion of physical depth. The main shadow layer sits 8px, 16px, and 24px offset from the original letter, with decreasing opacity to create natural falloff. Hover effects add an additional perspective rotation (rotateX: 5deg) and increased shadow for interactive feedback.
