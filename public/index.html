Under the Hood

GPU Parallelism Explained

Understand how Symmetra scales to millions of requests by leveraging GPU architecture.

⚙️

Threads

Single execution units. NVIDIA GPUs run thousands of threads in parallel. RTX 4090 has 16,384 CUDA cores = 16K simultaneous threads.

One thread = 1 computation unit
🔄

Warps

Groups of 32 threads that execute in lockstep (same instruction, different data). This is NVIDIA's SIMT (Single Instruction, Multiple Threads) model.

1 warp = 32 threads (locked in sync)
📦

Blocks

Groups of warps that share L1 cache and local memory. Blocks can synchronize threads, enabling complex parallel algorithms.

1 block = N warps = 32N threads
🌐

Grid

Collection of blocks that execute independently across the GPU. No synchronization between blocks — true massive parallelism.

1 grid = M blocks (independent)
💾

Memory

Registers (per-thread, fastest), L1 cache (per-block), L2 cache (global), VRAM (24GB on RTX 4090).

Zero-copy pinned memory on RTX 4090
🌊

Streams

Independent execution pipelines. 32 concurrent streams in Symmetra = 32 async kernels running simultaneously with overlapped I/O.

Promise.all([a, b, c]) = 3 streams

Scalability Example: JSON Processing

Process 1 million JSON objects (10KB each) in parallel:

GRID LAYOUT
3906 blocks × 256 threads = 1M threads
TOTAL THROUGHPUT
1M threads × 2.5 Gh/s = 2.5 Th/s
TIME TO COMPLETION
10KB × 1M / 2.5Th/s ≈ 4ms

This is why Symmetra achieves 3.1M RPS — every request spawns thousands of GPU threads. No CPU bottleneck. No GC pauses. Pure compiled CUDA code.

Engines

Swappable Turing Machine Backends

Same TypeScript code compiles to different compute engines via the IComputeBackend abstraction. Choose hardware based on performance, cost, and availability.

CURRENT

GPU (CUDA)

⚡
Hardware: NVIDIA RTX 4090, H100, L40S
Throughput: 2.5 Th/s sustained
Per-Thread Speed: 78 Gh/s (highest)
Memory: 24GB VRAM, zero-copy I/O

Production-grade. Mature NVRTC compiler. Best cost-to-performance ratio today.

GPU (ROCm/HIP)

🔴
Hardware: AMD RX 7900, MI300, MI250
Throughput: 1.2 Th/s sustained
Per-Thread Speed: 67 Gh/s
Advantage: Open-source, lower cost

Same code as CUDA. AMD's ROCm or HIP compatibility layer. Perfect for cost-sensitive deployments.

TPU (Google)

🧠
Hardware: TPU v4, TPU v5e, Cloud TPU
Throughput: 3.4 Th/s (v5e) sustained
Per-Thread Speed: 85 Gh/s (highest)
Target: ML workloads, matrix ops

Tensor-optimized. Highest throughput for matrix-heavy code. Cloud-native infrastructure.

CPU (x86/ARM)

🖥️
Hardware: Intel Xeon, AMD Epyc, ARM Graviton
Throughput: 0.1-0.5 Th/s
Per-Thread Speed: 5-15 Gh/s
Use Case: Fallback, low-latency operations

Baseline execution engine. Same code runs on CPU if GPU unavailable. 50-100× slower but universally available.

FPGA

⚙️
Hardware: Xilinx Alveo, Intel Stratix
Throughput: 1-3 Th/s (custom logic)
Per-Thread Speed: 50-80 Gh/s
Benefit: Fully customizable hardware

Hardware synthesis. Reconfigurable circuits. Perfect for specialized algorithms and low-power deployments.

Custom ASIC

🔧
Hardware: Application-specific silicon
Throughput: 5-10 Th/s (theoretical)
Per-Thread Speed: 100+ Gh/s
Cost: $10M-$100M fab + design

Tape-out custom silicon. Peak performance. Requires volume to justify. Example: Google TPU, Tesla FSD chip.

Symmetra's Engine-Agnostic Architecture:

Write TypeScript once. Symmetra compiles to any Turing machine backend via the IComputeBackend interface. Deploy the same code on RTX 4090 (78 Gh/s/thread), Google Cloud TPU (85 Gh/s/thread), AMD MI300 (67 Gh/s/thread), CPU fallback (12 Gh/s/thread), or custom ASIC (100+ Gh/s/thread) — without changing application code. Choose hardware based on cost, latency, power, and availability. Perfect for enterprises managing heterogeneous infrastructure.
