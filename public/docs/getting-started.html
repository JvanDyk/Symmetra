Getting Started with Symmetra

Get up and running with Symmetra in 5 minutes. Compile TypeScript, execute on GPU, and achieve 3.2M RPS.

1. System Requirements

✓

NVIDIA GPU

RTX 2070 or newer (Compute Capability 7.5+). Check with: nvidia-smi

✓

CUDA Driver

Driver version 525 or newer. Download CUDA Toolkit

✓

OS Compatibility

Windows 10/11 or Linux (Ubuntu 20.04+, CentOS 8+)

2. Install Symmetra

Windows (PowerShell)

iex (iwr -Uri 'https://symmetra.io/install.ps1').Content

Linux (Bash)

curl https://symmetra.io/install.sh | bash

This will download the latest binary and add it to your PATH.

3. Create Your First Program

Create a file named server.ts:

export default async function handler(req: Request): Promise<Response> {
  const name = new URL(req.url).searchParams.get('name') || 'GPU';
  return new Response(JSON.stringify({
    message: `Hello from ${name}!`,
    timestamp: Date.now()
  }), {
    status: 200,
    headers: { 'Content-Type': 'application/json' }
  });
}

4. Run the Server

sym server.ts --port 3000

The server will compile your TypeScript to CUDA and launch on your GPU.

5. Test It

In another terminal:

curl 'http://localhost:3000?name=Symmetra'

You should see:

{"message":"Hello from Symmetra!","timestamp":1234567890}

Check that everything is working:

This will verify your GPU, CUDA driver, and system configuration.
