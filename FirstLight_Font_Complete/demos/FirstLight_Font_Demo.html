Installation Guide

Step 1: Copy Font File

Place FirstLight.ttf in your project directory (or a fonts folder)

Step 2: Add @font-face to CSS

@font-face { font-family: 'First Light'; src: url('FirstLight.ttf') format('truetype'); font-weight: normal; font-style: normal; }

Step 3: Use in HTML

<h1 style="font-family: 'First Light', Arial, sans-serif;"> FIRST LIGHT </h1>

Or in CSS

.my-heading { font-family: 'First Light', Arial, sans-serif; font-size: 120px; font-weight: normal; letter-spacing: 8px; }

CSS Properties Reference

/* Recommended CSS properties for best appearance */ .first-light-heading { font-family: 'First Light', Arial, sans-serif; font-size: 120px; font-weight: normal; /* Use normal, not bold */ letter-spacing: 8px; /* Generous letter spacing */ text-transform: uppercase; /* Typically used uppercase */ color: #ffffff; /* Works best with light colors */ text-align: center; /* Center alignment common */ line-height: 1.2; /* Tight line height */ }

The TTF font format is supported on:

  • Firefox: All versions (3.5+)
  • Safari: All versions (5.1+)
  • Edge: All versions
  • Opera: All versions (10.5+)
  • Mobile browsers: iOS Safari, Android Chrome, etc.

Advanced Usage

Creating a Fallback Font Stack

font-family: 'First Light', 'Arial Black', 'Arial Bold', Arial, sans-serif;

Using with CSS Variables

:root { --font-heading: 'First Light', Arial, sans-serif; --font-size-large: 120px; --font-spacing: 8px; } h1 { font-family: var(--font-heading); font-size: var(--font-size-large); letter-spacing: var(--font-spacing); }

Adding Text Shadow for Extra Depth

/* Add subtle shadow for cinematic effect */ .first-light { font-family: 'First Light', Arial, sans-serif; color: #ffffff; text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3), 4px 4px 8px rgba(0, 0, 0, 0.2); }

Font Customization

Want to add more characters to the font or modify the letter designs? The font generator script (generate_3d_font.py) can be customized to:

  • Add more letters (A-Z, a-z)
  • Include numbers (0-9) and symbols
  • Adjust letter geometry and proportions
  • Modify outline thickness
  • Create alternate versions

Edit the letter definitions in create_letter_outline() function in the Python script to customize the font.
