🎯 KEY CUSTOMIZATION OPTIONS:

Change Text Color:
    color: #00ff88;              /* Change to any color */

Adjust Shadow Depth:
    Modify pixel values (8px, 16px, 24px) in text-shadow

Change Letter Spacing:
    letter-spacing: 0.12em;      /* Increase/decrease gaps */

Disable Hover Effect:
    .text-3d:hover { transform: none; }

Change Font Size:
    font-size: 80px;             /* Any size you want */

🎬 DESIGN INSPIRATION:

This font system is inspired by professional cinematic title sequences.
The 3D depth effect uses:
  • Layered shadows at multiple angles
  • Perspective transform (3D tilt)
  • Variable opacity for atmospheric fade
  • Soft blur for natural light diffusion
  • Interactive hover animations

Result: Professional, modern, cinematic text effect without images or external libs.

📝 COMMON TASKS:

Make the shadow darker:
    Change rgba(0, 0, 0, 0.4) to rgba(0, 0, 0, 0.6)

Make the shadow lighter:
    Change rgba(0, 0, 0, 0.4) to rgba(0, 0, 0, 0.2)

Make shadow shallower:
    Use 4px, 8px, 12px instead of 8px, 16px, 24px

Make shadow deeper:
    Use 12px, 24px, 36px, 48px for extreme depth

Use neon colors:
    <h1 class="text-3d-neon">YOUR TEXT</h1>

Disable animations:
    Add: pointer-events: none; to .text-3d:hover
