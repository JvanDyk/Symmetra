  QUICK START (Choose Your Path)
════════════════════════════════════════════════════════════════════════════════

PATH 1: SEE IT FIRST (5 minutes)
─────────────────────────────────
  1. Open: demos/FirstLight_Font_Visual_Preview.html
  2. View in browser to see font styling and examples
  3. Read CSS code samples
  4. Proceed to Path 2 or 3

PATH 2: USE IN WEB PROJECT (10 minutes)
──────────────────────────────────────────
  1. Copy: font/FirstLight.ttf → your project folder
  2. Add to CSS:
     @font-face {
         font-family: 'First Light';
         src: url('FirstLight.ttf') format('truetype');
     }
  3. Use in HTML: <h1 style="font-family: 'First Light'">FIRST LIGHT</h1>
  4. Done! 🎉

PATH 3: INSTALL SYSTEM-WIDE (Windows - 1 minute)
──────────────────────────────────────────────────
  1. Right-click: font/FirstLight.ttf
  2. Click: "Install" or "Install for all users"
  3. Font now available in Word, Photoshop, all apps
  4. Done! 🎉

PATH 4: CUSTOMIZE FONT (Advanced)
─────────────────────────────────
  1. Edit: scripts/generate_3d_font.py
  2. Add new letters, numbers, or symbols
  3. Run: python scripts/generate_3d_font.py
  4. Get: New FirstLight.ttf with your changes
  5. Use the new font in your projects
