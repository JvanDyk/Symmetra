Quick Start Guide

For Web Projects:

@font-face { font-family: 'First Light'; src: url('FirstLight.ttf') format('truetype'); } h1 { font-family: 'First Light', Arial, sans-serif; font-size: 120px; letter-spacing: 8px; }

For System-Wide Installation:

  • Right-click FirstLight.ttf
  • Select "Install" (or "Install for all users")
  • Font is now available in Word, Photoshop, and all applications
