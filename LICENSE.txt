DISCLAIMER OF LIABILITY

This software is provided as-is for research, development, and production use.
While we have made every effort to ensure the software is reliable and
production-ready, the following disclaimers apply:

1. GPU COMPATIBILITY
   This software requires an NVIDIA GPU with compute capability 7.5 or higher
   (RTX 2070 or newer). Some features may not work with older GPUs.

2. CUDA DRIVER REQUIREMENTS
   You must have NVIDIA CUDA driver version 13.1 or higher installed.
   Incompatible or outdated drivers may cause failures.

3. PERFORMANCE CHARACTERISTICS
   Performance metrics are measured under specific hardware and software
   configurations. Your actual performance may vary based on:
   - GPU model and generation
   - Driver version
   - CUDA version
   - System load and other applications
   - Network conditions

4. SECURITY CONSIDERATIONS
   While we have implemented security features (input validation, TLS support),
   you are responsible for:
   - Securing your deployment environment
   - Keeping CUDA drivers and OS updated
   - Monitoring logs for security events
   - Implementing appropriate firewall rules
   - Regular security audits of your deployment

5. PRODUCTION DEPLOYMENTS
   Before deploying to production:
   - Test thoroughly in a staging environment
   - Verify performance meets your requirements
   - Implement monitoring and alerting
   - Have a backup and recovery plan
   - Review and follow the DEPLOYMENT_GUIDE.md
